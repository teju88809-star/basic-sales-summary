# basic-sales-summary
Basic Sales Summary using the Kaggle Sample Superstore dataset. Calculates Total Sales, Average Sales, and Transaction Count using Excel formulas and presents key business performance indicators (KPIs) in a summary report.
 Basic Sales Summary

Project Overview

This project focuses on creating a basic sales summary using the Kaggle Sample Superstore dataset. The objective is to calculate key sales metrics and present them in a simple business summary.

Objectives

- Calculate Total Sales.
- Calculate Average Sales.
- Calculate Transaction Count.
- Understand basic business KPIs using Excel.

Dataset

- Dataset Name: Sample Superstore
- Source: "Kaggle – Sample Superstore Dataset" (https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- Format: CSV
- Tool Used: Microsoft Excel

KPIs

1. Total Sales: Sum of all sales values.
2. Average Sales: Average of the numeric sales values.
3. Transaction Count: Number of numeric sales entries.

Excel Formulas

Assuming the Sales column is column S and the data runs from row 2 to row 9995:

- Total Sales: "=SUM(S2:S9995)"
- Average Sales: "=AVERAGE(S2:S9995)"
- Transaction Count: "=COUNT(S2:S9995)"

Check the downloaded dataset's column layout and last row before using these formulas.
